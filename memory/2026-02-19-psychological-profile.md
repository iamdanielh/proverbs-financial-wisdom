## Core Thinking Architecture

### 1. Opening Style: Scenario-Based Hypothesis Testing
- **Pattern:** "if you had to make a script..." / "Explain X to me" → immediate followup
- **Insight:** Doesn't ask for facts; asks for judgment on imagined scenarios
- **Examples:**
  - Biblical Finance: *"if you had to make a script for a viral video..."*
  - Dataism: *"So harari put into words the worldview?"*
  - Bangkok: *"ayudame a iniciar mi capítulo... de una forma cautivadora"*

### 2. Verification Frequency: High
- **Pattern:** Consistently validates before accepting
- **Language:** "does that make sense?" / "is that right?" / "does that make sense theologically?"
- **Insight:** Even questions authority — expects answers to be provisional

### 3. Collaboration Model: Iterative Refinement
- **Stats:** High back-and-forth ratio (Dataism: 200 user msgs / 229 AI msgs = 0.87:1)
- **Pattern:** Direction, not replacement — "se más breve" / "de una longitud similar pero..."
- **Insight:** Works WITH AI to shape, not just consume output
